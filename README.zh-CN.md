## ✨ 包含的技能

| 技能 | 功能 |
|------|------|
| ✅ **medxpert-termbase** | 双语法规术语库与译稿质检（164 个术语，36 个误译规则） |

| ✅ **reg-citation-normalizer** | 法规引用规范化（21 CFR / ISO / NMPA 标准格式） |

## 🚀 快速开始

一行命令安装：

```bash
npx skills add stevenzhao07/medxpert-skills
```

然后问你的 AI Agent：
- "帮我算一下这个 ISO 14971 风险"
- "检查一下我的 IFU 翻译有没有常见错误"
- "规范化这个法规引用"
