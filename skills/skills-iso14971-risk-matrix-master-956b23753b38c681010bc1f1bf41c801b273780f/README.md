# ISO 14971 Risk Matrix — 风险矩阵计算与风险管理文件自查

给医疗器械质量/注册团队用的 **ISO 14971 风险管理小工具**。

## 它解决什么

风险文件被审核开缺陷，十次有八次不是"没做"，而是**记录里看不出做过**：

- 风险矩阵用了企业自己的准则，但和风险管理计划对不上
- 控制措施写了一堆，措施前后的风险值**一模一样**（等于没降下来）
- 剩余风险还是高风险，却没做获益-风险分析
- 风险管理文件缺 §7.3 剩余风险评价、缺 §8 整体剩余风险、缺 §10 生产和生产后活动

本技能把上述检查做成**可执行命令**。

## 能力

```bash
# 参考矩阵（5x5）
python scripts/risk_matrix.py matrix

# 评估一条风险
python scripts/risk_matrix.py assess -s 4 -p 2

# 一次给出措施前后（初始 + 剩余）
python scripts/risk_matrix.py assess -s 5 -p 5 --rs 2 --rp 1

# 风险控制方案优先级（ISO 14971:2019 §7.1）
python scripts/risk_matrix.py options

# 风险管理文件完整性自查（16 个要素覆盖 ISO 14971:2019 §4–§10）
python scripts/risk_matrix.py check risk_management_file.md
```

`assess` 除了算等级，还会：

- 打印 **ISO 14971:2019 第 3 章词汇链**（危害 → 事件序列 → 危险情况 → 伤害），提示自查有没有断链
- 给出措施前后对比，并**主动报可疑情况**：剩余风险仍为高、反而升高、或与初始完全相同

`check` 按 16 个要素逐条核对，关键要素（计划、文件、预期用途、危害识别、风险估计、风险评价、控制方案分析、措施实施与验证、剩余风险评价、整体剩余风险、管理评审、生产后活动）单独列出缺失项。

## 使用须知（请注意）

- **矩阵是行业常用约定，不是标准规定。** ISO 14971:2019 §4.4 明确要求由制造商在风险管理计划中自定可接受性准则——正式文件必须引用你企业的计划，本工具的输出会自己把这一点写在明面上。
- 概率锚点（1e-6 ～ 1e-2 / 器械寿命）仅为示意，**并非标准原文**。
- `check` 是关键词命中检查，只支持中英文。命中 ≠ 该要素实质完成，仍需人工读。
- 本工具**不代写风险文件、不代替你做可接受性判定、不构成法规意见**。
